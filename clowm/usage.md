# Input

Searching for local alignments with PLAST requires two different kinds of input:

* A DNA sequence that serves as query, and
* a pangenome to search in.

## The Query Sequence

The query sequence is a plain text file containing a continuous string representing a [DNA sequence](#dna-sequence) to search for. A query sequence file may contain multiple lines each with a different string making it possible to search for alignments for multiple DNA sequences in only a single run of PLAST.

## The Pangenome

PLAST expects a pangenome to be represented as a [Bifrost graph](#pangenome-input-as-bifrost-graph). However, it is also possible to use a [set of genomes](#pangenome-input-as-set-of-genomes) as input which form the pangenome. Required files and their formats for both cases are described in detail below.

### Pangenome Input as Bifrost Graph

A Bifrost Graph consists of two files storing different kinds of information. Optionally, a third file may exist representing an index for faster loading. All files need to share the same file name prefix in order to be recognised as belonging together. 

Sequence information is stored in a [GFA file](https://gfa-spec.github.io/GFA-spec/GFA1.html) (with file suffix `.gfa`). [GZipped](https://en.wikipedia.org/wiki/Gzip) GFA files (with file suffix `.gfa.gz`) are possible, too. 
**ATTENTION**: While the GFA format is a general format that may be generated by many different tools, PLAST will only work correctly if GFA files generated by the tool [Bifrost](https://github.com/pmelsted/bifrost) are used. 

[Color information](#color-information) is stored in a file with the file suffix `.color.bfg` (again generated by the tool [Bifrost](https://github.com/pmelsted/bifrost).

An optional Bifrost index file is stored in a file with file suffix `.bfi`.

# Glossary

## DNA Sequence

DNA sequences may be defined over various alphabets. Here, DNA sequences are meant to only contain the characters 'A', 'C', 'G', and 'T'.

## Color Information

In pangenomics, it is often necessary to distinguish between the origin of a [DNA sequence](#DNA_Sequence), i.e., the individual genome it stems from. Throughout this document, we call this kind of information *color information* or simply *color*.
